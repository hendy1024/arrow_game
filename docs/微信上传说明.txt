微信上传包超限处理
================
报错中的 source size 9309KB exceed max limit 4MB 表示源码包大小超限。
原始运行文件本地统计约0.91MiB，微信编译后的最终大小需要在开发者工具确认。

本次调整：
1. 开启代码压缩 minified。
2. 关闭上传源码映射 uploadWithSourceMap。
3. 开发工程排除开发目录。
4. dist\wechat 内生成独立的 project.config.json，根目录只含运行文件。
5. 构建自动检查运行文件清单与4MiB边界；多余文件或超限时明确报错。

推荐上传方式：
在微信开发者工具中新增/导入项目，目录选择：
F:\User\wechat_game\codex\arrow-game\dist\wechat
AppID：wx47e5456f2f4f5ade
此目录的项目名称为 arrow-garden-upload。
重新编译后再预览或上传。

以后仍在原工程修改代码/配置，执行 npm run build 后，
此上传目录会同步更新。不要直接在dist目录修改游戏代码。

该报告统计未经微信编译的运行文件，不等于微信最终上传体积。
