# 一键编译上传

双击项目根目录的 `upload-wechat.cmd`，输入自定义版本号和版本说明即可。

脚本先运行全部测试，再构建最新代码、检查运行包大小，然后打开微信工程并调用微信开发者工具完成编译上传。任何一步失败都会停止，不上传未通过检查的版本。

只上传 `dist/wechat`，不会上传源码工程、旧 ZIP 包、测试或图标资料。

首次使用：安装 Node.js 22 或更高版本，打开微信开发者工具并登录；在开发者工具“设置 → 安全设置”中开启服务端口。若启用了 CLI 访问令牌，在当前终端设置 `WECHAT_DEVTOOLS_CLI_TOKEN`。脚本不修改微信安全设置，也不保存令牌。

命令行用法（在项目根目录）：

```powershell
npm run upload -- --version 1.0.1 --desc "调整音乐和道具说明"
```

自定义安装目录：

```powershell
npm run upload -- --version 1.0.1 --desc "更新说明" --tools-dir "D:\微信web开发者工具"
```

只检查、不上传：

```powershell
npm run upload -- --version 1.0.1 --dry-run
```

版本号支持字母、数字、点、横线和下划线，不会修改 package.json 的版本号。每次成功上传会输出此次上传信息文件的位置，保存在 reports 文件夹。

上传完成只是生成微信开发版本，不会自动设置体验版、提审或正式发布。上传报错时，按原错误修复后重新运行；若发生网络中断且结果不明确，先查看微信后台是否已有该版本，再决定是否重试。

命令参数已根据本机微信开发者工具 `upload --help` 验证。
