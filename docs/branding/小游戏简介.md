# 箭间

一句话简介：让每条箭头，找到出口。

微信后台简介：

观察箭头方向，找出畅通出口。解开层层交错的箭头棋盘，挑战障碍、限时关卡与每日每周竞速。

详细介绍：

《箭间》是一款箭头消除益智小游戏。点击前方没有遮挡的箭头，看它沿着路径移出棋盘；理清消除顺序，让每条箭头都找到出口。

20 个关卡逐步提升难度，密集的折线箭头、障碍与倒计时考验观察和判断。加时、容错和重排道具助你继续挑战，还可通过关卡总览查看奖励、选择已解锁关卡重玩。

通关第 4 关后解锁竞速模式，在每日或每周固定赛道上连续挑战 3 关，刷新个人纪录，与微信好友比较用时。
