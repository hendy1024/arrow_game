普通关卡与奖励配置说明（20关高难版）
===================================

一、配置文件
config\campaign-levels.json：游戏直接读取的20关完整棋盘与奖励。
config\campaign-pacing.json：生成固定棋盘时采用的各关难度目标。

每个关卡对象包含：
id：连续关卡编号1—20。
rewards：首次通关奖励；{}表示无奖励。
board：完整布局，包括width/height、arrows、obstacles、lifeLimit、timeLimitMs。

奖励示例：
"rewards": { "time": 2, "life": 1, "shuffle": 3 }
time=加时，life=容错，shuffle=重排；数量为1—1000的整数。
只改奖励时，不需要调整board。

二、当前节奏
第1关：入门教学。
第2关：20×20，120秒，3次容错，最低32层遮挡。
第4关：开始加入2个障碍。
第2—20关：棋盘大小、遮挡目标、箭头最大长度按指数参数增长。
第20关：32×32，75秒，12个障碍，最低56层遮挡，箭头最多26格。
所有挑战关均为满棋盘、开局仅一条可移除，完整布局均经过可解验证。
第2—20关平均箭头长度至少从6格逐步增长至7格。
实际参数以两个JSON文件为准。

三、修改和生效
只调整某关奖励：修改campaign-levels.json的rewards，然后执行 npm run build。
调整固定布局：修改board后执行 npm run build，构建会检查是否可解。
按目标重新生成：修改campaign-pacing.json，执行 node scripts/tune-campaign.cjs，再执行 npm run build。
高难布局的筛选可能耗时数分钟。全部目标满足后才写入新关卡，不降低要求来强行通过。
最后在微信开发者工具中重新编译、扫码预览；正式玩家需发布更新。
推荐导入上传目录：F:\User\wechat_game\codex\arrow-game\dist\wechat。
源代码和配置仍在外层arrow-game中修改，不直接改dist。

四、总览与记录
一页显示全部20关，已通关关卡可以重玩，锁定关卡可以查看奖励。
小人标记当前未通关关卡。第20关完成后可回总览继续挑战。
首次通关自动发奖，重玩或手动重置普通进度不重复发奖。
使用道具的对局不计个人最快用时；布局或限制修改后纪录分开。
密集棋盘可使用放大、拖动；点击最近箭头，障碍中心不触发相邻箭头。

五、容错续关
点错使容错降到0时弹出提示。确认使用1个容错道具后恢复1次机会，继续当前棋盘。
提示期间动画和倒计时停止；取消则结束本局，库存为0时无法续关。
超时失败不能通过容错道具继续。竞速模式不限点错，不出现此提示。

六、旧版本升级
按用户确认，旧100关进度、解锁状态、普通最快纪录和领取记录一次性清空。
道具库存、声音/震动设置保留；竞速历史不删除。
新存档标记campaignRevision=3，后续打开正常续玩，不重复清空。
此后的布局调整仍保留未完成存档；从总览重新挑战读取最新布局。
