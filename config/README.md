# 竞速难度配置

编辑 `race-difficulty.json`，daily和weekly分别配置3个递增的 `campaignLevel`，引用普通关卡难度。

- 每日：普通第5、10、15关。
- 每周：普通第5、15、25关。
- 同周期同布局；按日期旋转或镜像，保留可解性和难度。
- 不限时、不扣容错、不使用道具，统计3关总用时。

修改后执行 `node scripts/build.cjs`，重新编译预览。完整文字说明见 `配置说明.txt`；普通关卡说明见 `普通关卡配置说明.txt`。


## 2026-09-13：40关、数量门、钥匙门和每日领奖（覆盖上述旧规则）

普通关卡共40关，总览每页20关，通关20关解锁第二页。第2关仍为25×25高密度棋盘；21关起采用竖向长方形棋盘。普通非教学关保留密集长箭头、单初始出口和高遮挡深度，所有布局由独立求解器验证。

前10关每关300秒；11关起每关缩短4秒，到40关180秒。第4关首次出现4个永久障碍，之后每关增加1个，到40关40个。第4、8、12关是简单教学关，采用较少箭头和更浅的消除顺序，下一关恢复高难度。教学弹窗、暂停及后台不计时。

第8关引入数量门，移出指定数量的普通箭头后自动打开，门面显示还需数量；钥匙箭头不计入普通箭头数量。第12关引入钥匙门，钥匙箭头有专属颜色和钥匙图标，完全移出后打开对应颜色的门。13关起组合两种门，后续逐渐增加钥匙门。重排保留开门进度和钥匙对应关系，不产生死局。教学说明可点击按钮或空白区域关闭。

首通奖励改在4n−1关（n为正整数），即3、7、11、15、19、23、27、31、35、39关；每次加时1个、容错2个、重排1个。已领取关卡不重复发奖。主页新增每日奖励按钮，每天免费领取加时、容错、重排各1个，领取后显示已领取；北京时间零点换日，与每日分享各5个的奖励分别计算。每次通关奖励、每日奖励和分享奖励都展示带道具图标及数量的物品弹窗，关闭不重复发奖。

保留现有解锁进度、道具库存和领取记录；正在玩的旧棋盘保留原布局，倒计时按新上限减去已用时迁移一次，新开关卡使用新布局。重置进度不重置每日领取额度。竞速仍通关4关解锁、3关、无道具不限错不限时；每日引用5/10/15，每周改为5/15/25，避免将新手教学关当成周赛高难关。配置变更隔离旧竞速布局成绩。
